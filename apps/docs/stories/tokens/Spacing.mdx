# Spacing

A consistent spacing scale used across all components for margins, paddings, and gaps. These are **global tokens** — used directly, with no semantic alias layer.

For unit strategy (`px` vs `rem`), see **[Tokens/Units (px vs rem)](?path=/docs/tokens-units-px-vs-rem--docs)**.

  <strong>Import:</strong>{" "}

## Usage

```ts
import { spacing, padding } from "@billabex/ui-tokens";

spacing.md.value   // 8
spacing.md.px      // '8px'
spacing.md.rem     // '0.5rem'
`${spacing.md}`    // '8px' (toString)

padding.card.px    // '16px'
padding.page.px    // '24px'
```

> In components, prefer `spacing.*.rem` for scalable layout by default, and use `.px` only when pixel precision is required.
