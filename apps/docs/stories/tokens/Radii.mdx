# Border Radius

Border radius tokens for consistent rounding across all components. These are **global tokens** — used directly, with no semantic alias layer.

<Tip>
  <strong>Import:</strong>{" "}
  <code>{"import { radii } from '@billabex/ui-tokens'"}</code>
  <br />
  {"Each token exposes "}<code>.value</code>{" (number), "}<code>.px</code>{", "}<code>.rem</code>{", and "}<code>toString()</code>{"."}
</Tip>

## Usage

```ts
import { radii } from "@billabex/ui-tokens";

radii.sm.px     // '8px'
radii.md.px     // '12px'
radii.full.px   // '9999px'

// Use in inline styles
<div style={{ borderRadius: radii.sm.px }} />
```
