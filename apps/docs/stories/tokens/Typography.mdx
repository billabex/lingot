# Typography

All text styles in the design system. The typeface is **Outfit** with weights 300, 400, 500, and 600. These are **global tokens** — used directly, with no semantic alias layer.

> **Font loading** is the consumer's responsibility. Load Outfit via Google Fonts or self-host: `<link href="https://fonts.googleapis.com/css2?family=Outfit:wght@300;400;500;600&display=swap" rel="stylesheet">`.

For unit strategy (`px` vs `rem`), see **[Tokens/Units (px vs rem)](?path=/docs/tokens-units-px-vs-rem--docs)**.

## Usage

```ts
import { typography } from "@billabex/ui-tokens";

typography.body.fontFamily        // 'Outfit, sans-serif'
typography.body.fontWeight        // 400
typography.body.fontSize.px       // '14px'
typography.body.lineHeight.px     // '20px'

typography.display.fontSize.rem   // '2rem'
```

> For component CSS, prefer `typography.*.fontSize.rem` and `typography.*.lineHeight.rem` by default.
